# 唐纳森 Direct Flow 1200 滤芯三维（布置用）

按唐纳森公开外形尺寸，并结合实物照片特征建模。  
**不是唐纳森官方 CAD**，内部滤纸/波纹通道为外观示意，用于装配布置、空间校核。

## 文件（SolidWorks 直接打开）

| 文件 | 件号 | 外形包络（mm） |
|---|---|---|
| `DBA5293_Primary.STEP` | DBA5293 主滤 PowerCore | **267 × 267 × 331.5** |
| `P633484_Safety.STEP` | P633484 安全滤（板式） | **286 × 265 × 37.5** |
| `DirectFlow1200_FilterKit.STEP` | 两件并排放置 | — |

本环境无法写出原生 `.sldprt`。STEP 是 SolidWorks 标准交换格式：

1. SolidWorks → **文件 → 打开** → 选对应 `.STEP`
2. 导入实体后 **另存为** `DBA5293.sldprt` / `P633484.sldprt`

单位：毫米。坐标系：方法兰/板面在 XY，高度沿 Z。

## 模型里有什么

**DBA5293（按你拍的实物）**

- 267 mm 圆角方法兰 + 周圈密封唇
- 方端 8 根辐条 + 中间圆环 + 四角斜筋 + 中心毂
- 蓝色圆筒滤材（直径按照片相对方法兰约为 222 mm）
- 圆端盖、中心凹槽加强筋、两个八边形提手凸台

**P633484**

- 黑框、周圈密封槽、外壁筋
- 褶皱滤材示意、四道胶线
- 两只折平的钢丝提手

## 重新生成

```bash
python3 cad/donaldson/generate_filters.py
```

需要 Python 包 `cadquery`。圆筒直径、筋宽等可在脚本顶部常量里改。
