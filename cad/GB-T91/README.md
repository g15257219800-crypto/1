# GB/T 91-2000 开口销 φ2 mm（标准件库）

开口销按国标紧固件取库，不自行建模。本规格来自 **PartsCAD / 易紧通** 标准件三维库：

**GB/T 91 2×10**（公称直径 2 mm，公称长度 L = 10 mm），等效 ISO 1234:1997。

标准中 φ2 的销体直径 d 为 1.7–1.8 mm（公称直径等于销孔直径，销体略细以便穿入）。

## 文件

| 文件 | 说明 |
|------|------|
| `GB-T91_2x10.stl` | 二进制 STL，可进 SolidWorks / NX / Inventor |
| `GB-T91_2x10_partscad.json` | PartsCAD 目录三维（Three.js BufferGeometry） |
| `GB-T91_2x10_preview.png` | 三维预览 |
| `GB-T91_2x10_side.png` | 侧视 |
| `GB-T91_2x10_drawing.png` | 易紧通 2×10 尺寸图 |
| `GB-T91_schematic.png` | GB/T 91 结构示意图（a/b/c/d/L） |
| `source.json` | 来源与包络 |

包络约 **16.48 × 1.80 × 3.59 mm**（含眼圈与长脚），与标准 2×10：L=10、b≈4、a=1.25–2.5、c=3.2–3.6、d=1.7–1.8 一致。

目录里另有默认规格 `GB-T91_0.6x4.*`（易紧通 0.6×4）。

## 标准关系

| 标准 | 名称 |
|------|------|
| GB/T 91-2000 | 开口销 |
| ISO 1234:1997 | Split pins（GB 等效采用） |
| DIN EN ISO 1234 / DIN 94 | 开口销 |
