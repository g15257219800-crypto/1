# GB/T 91-2000 开口销（标准件库）

开口销是国标紧固件，不按非标零件建模。本目录文件来自 **易紧通 YJT 标准件三维库**（CATIA 导出 STL），对应 GB/T 91-2000，等效 ISO 1234:1997。

目录三维默认规格：**0.6×4**（公称直径 0.6 mm，公称长度 L = 4 mm）。标准标记示例：`GB/T 91 0.6×4`。

## 文件

| 文件 | 说明 |
|------|------|
| `GB-T91_0.6x4.stl` | 二进制 STL，可进 SolidWorks / NX / Inventor 预览 |
| `GB-T91_0.6x4_yjt_catia.stl` | 易紧通原文件（ASCII，`solid CATIA STL`） |
| `GB-T91_0.6x4_preview.png` | 三维预览 |
| `GB-T91_0.6x4_side.png` | 侧视 |

| `GB-T91_schematic.png` | GB/T 91 结构示意图（a/b/c/d/L） |
| `source.json` | 来源与包络尺寸 |

坐标系单位 mm。包络约 **7.60 × 0.50 × 1.00**（含头部眼圈与长脚）。

## 标准关系

| 标准 | 名称 |
|------|------|
| GB/T 91-2000 | 开口销 |
| ISO 1234:1997 | Split pins（GB 等效采用） |
| DIN EN ISO 1234 / DIN 94 | 开口销 |

公称直径等于开口销孔直径。标准系列：0.6、0.8、1、1.2、1.6、2、2.5、3.2、4、5、6.3、8、10、13、16、20 mm。按协议可用 3、6、12 mm。

## 其它规格
