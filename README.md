# 派克 EMA3 接头与法兰连接

本仓库给出派克 **EMA3 外螺纹测压接头** 接到液压法兰 / 管法兰上的连接设计。

EMA3 测压端固定是 **M16×2**（ISO 15171-2：锥面 + O 形圈一次密封，帽/软管二次密封）。油口端才是 G1/4 ED 或 ISO 6149 那些圈，两头不要混。默认做法：

- **新制件**：法兰颈加工 ISO 6149-1 M14×1.5 诊断油口，拧入 `EMA3/14X1.5ISO`
- **已有 SAE 四螺栓法兰**：加装测压隔板，不改原法兰
