# 08 速查表与排错

## 快捷键（默认，可在自定义里改）

| 键 | 作用 |
|----|------|
| Ctrl+N / S / Z / Y | 新建 / 保存 / 撤销 / 重做 |
| Ctrl+R | 重计算文档 |
| Space | 显示或隐藏选中对象 |
| Del | 删除（先看树，别删错 Body） |
| 1 / 3 / 7 / 0 | 前视 / 右视 / 顶视 / 等轴测（数字键盘） |
| V, F | 缩放到所选 |
| V, 2 / V, 3 | 实体着色 / 线框 |

草图模式（1.0/1.1 常用，以状态栏提示为准）：

| 键 | 作用 |
|----|------|
| Esc | 退出当前工具；再按可关草图 |
| Ctrl 拖动 | 禁用捕捉（画斜线时有用） |

## 建模时的检查清单

1. 当前是否在 **零件设计**，且正确的 **Body 已激活**？
2. 草图是否 **闭合**、端点 **重合**？
3. 是否 **完全约束**（绿）？欠约束能填充，但拖点会把下游特征搞乱。
4. 开槽是否选了 **贯通**？
5. 改早期草图后，圆角是否变红？变红就重新选边。

## 报错与处理

| 报告视图 / 对话框 | 原因 | 处理 |
|-------------------|------|------|
| Wire not closed / invalid shape | 草图开口、线重叠 | 校验草图，修剪，补重合 |
| Failed to create pad | 轮廓自交、零厚度 | 去掉交叉，检查缩放是否把尺寸弄成 0 |
| Over-constrained | 约束冲突 | 删除求解器标红的约束 |
| Recompute failed / 特征黄色 | 附着面丢了（拓扑命名） | 草图改附着到基准面；或右键特征重新选参照 |
| Boolean operation failed | 实体不相交或共面接触不良 | 略微偏移再布尔；零件设计里改用开槽 |
| 中文路径插件异常 | 个别宏假设 ASCII 路径 | 工程放到英文目录 |

拓扑命名：改了前面的填充，后面“第 3 个面”可能变成另一个面。1.0+ 已改善，但仍建议 **先做主体形状，打孔圆角放后面**；关键草图附着 **基准平面 / 基准轴**。

## 性能

- 一个文档里不要堆几十个互不相关的零件，拆文件。
- 阵列数量很大时先用粗参数，确认再加密。
- 关闭不需要的工作台（首选项里可减少启动加载）。
- 圆角选一圈 200 条边会明显变慢，能在草图画圆角就在草图里做简单轮廓。
