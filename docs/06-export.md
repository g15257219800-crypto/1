# 06 导出、打印与协作

模型做完后，按下游选择格式。参数文件永远留一份 `.FCStd`。

## 格式怎么选

| 格式 | 谁在用 | 特点 |
|------|--------|------|
| `.FCStd` | 你自己 | 完整历史，以后还能改草图 |
| **STEP** (`.step` / `.stp`) | 机加、其他 CAD、同事 | 精确 B-rep，推荐作为交换格式 |
| **IGES** | 老软件 | 有时丢颜色/名称，不如 STEP |
| **STL** | 3D 打印、切片软件 | 三角网格，不可参数化 |
| **OBJ / 3MF** | 打印、展示 | 3MF 可带颜色与单位 |
| **PDF** | 图纸 | 从 TechDraw 导出 |
| **DXF** | 激光切割 2D | 从草图或 TechDraw 导出，先确认单位 |

## 导出 STEP

1. 模型树选中 **Body**（不要只选一个中间 Pad，除非你真的只要那一块）。
2. **文件 → 导出** → 类型选 STEP。
3. 选项里尽量用 **AP214** 或 **AP242**，勾选导出颜色（若有）。

发给工厂或 SolidWorks / NX 用户时，STEP 是默认选择。

## 导出 STL（3D 打印）

1. 选中实体。
2. **文件 → 导出** → STL。
3. 网格过粗会出现圆孔变多边形。导出前可选：选中对象 → **网格工作台 → 从形状创建网格**，偏差（Deviation）调到 **0.05～0.1 mm** 量级再导出。
4. 切片软件（Cura、PrusaSlicer、Orca）里确认单位是 **毫米**。FreeCAD 默认 mm，若打印只有“几毫米大”，多半是对方软件按英寸读了。

L 支架打印建议：

- 平放底板，立板朝上，少支撑。
- 层高 0.2 mm，孔直径 8 给螺丝时按打印机误差做 ±0.2～0.3 mm 补偿（在草图改直径最干净）。
- PETG / ABS 比 PLA 更适合承力支架。

## 导出 2D（激光 / 水刀）

- 只有一层轮廓：打开草图 → 导出 DXF。
- 要从实体“拍”出外形：零件工作台投影，或 TechDraw 视图再导出 DXF。
- 检查 DXF 是 mm 还是英寸，切割机软件里对一下。

## 与其他软件协作

- **Blender / 渲染**：OBJ 或 STEP（Blender 需插件读 STEP）。
- **仿真**：STEP 进 FEM 工作台，或导出给其他求解器。
- **版本管理**：`.FCStd` 是压缩包，Git 里会当成二进制。可用 Git LFS，或只把 STEP/STL 纳入版本库。

## 导入别人的模型

**文件 → 导入**。STEP 进来是“无历史”形状，要改结构通常得：

- 小改：零件工作台切、倒角；或
- 大改：量关键尺寸，在零件设计里重做。

网格 STL 导入后是 Mesh 对象，不能直接当 Body 填充。需要的话用网格转换尝试转实体，复杂扫描件往往转不好。

## 安全

1.1.3 起的维护版修复了恶意 FCStd 导致代码执行等问题。不要打开不信任来源的工程文件；宏（`.FCMacro`）更要先读内容再运行。
