# 01 安装与中文界面

目标：装好 FreeCAD 1.1，切到简体中文，把单位和鼠标操作调到适合机械建模的状态。

## 下载

只从官网或 GitHub 发行页下载：

- 官网：<https://www.freecad.org/downloads.php>
- GitHub Releases：<https://github.com/FreeCAD/FreeCAD/releases>

当前稳定版是 **1.1.3**。安装包都是 64 位。不要用来路不明的“汉化破解包”。

| 系统 | 最低版本 | 推荐安装方式 |
|------|----------|----------------|
| Windows | Windows 10 | `x86_64 installer`（.exe） |
| macOS | macOS 12 Monterey | `.dmg`（Apple Silicon 与 Intel 分开） |
| Linux | 视发行版而定 | 官网 **AppImage**，或发行版仓库 / Flatpak |

Windows 另有便携版 `.7z`，解压即可运行，适合没有管理员权限的电脑。

## Windows

1. 运行安装程序，按默认路径即可。
2. 完成后桌面会有 FreeCAD 图标。
3. 第一次启动可能稍慢，属于正常（在编译着色器、加载工作台）。

## macOS

1. 打开 `.dmg`，把 FreeCAD 拖进“应用程序”。
2. 若提示“无法验证开发者”，到 **系统设置 → 隐私与安全性** 允许打开。
3. Apple Silicon（M 系列）务必下载 **arm64** 包，不要用 x86_64 再靠转译硬跑。

## Linux（AppImage，最省事）

```bash
chmod +x FreeCAD_*-Linux-x86_64-*.AppImage
./FreeCAD_*-Linux-x86_64-*.AppImage
```

部分系统还要装 FUSE。Debian/Ubuntu：

```bash
sudo apt install libfuse2
```

也可以用 Flatpak：`flatpak install flathub org.freecad.FreeCAD`。

## 切到简体中文

默认界面是英文。路径：

**编辑 → 首选项 → 常规 → 语言** → 选择 **简体中文**（`Chinese, Simplified`）→ **应用**。

多数版本立刻生效；若菜单仍是英文，关掉 FreeCAD 再打开一次。

同一页建议一并确认：

- **单位**：`Standard (mm, kg, s, °)` 或 `MKS (m, kg, s, °)`。机械零件请用 **毫米**。
- **启动**：可把默认工作台设为 **零件设计**，少点一次下拉框。

## 导航样式（鼠标怎么转模型）

**编辑 → 首选项 → 显示 → 导航**，导航样式建议：

| 设备 | 推荐样式 | 操作 |
|------|----------|------|
| 鼠标（三键） | **CAD**（默认） | 中键平移；先按中键再按左键旋转；滚轮缩放 |
| 笔记本触控板 | **Gesture** 或 **Blender** | 按屏幕左下角提示练习，避免和系统手势冲突 |

3D 视图左下角的立方体可以一键切到前视 / 顶视 / 等轴测。数字键盘（若有）：

- `1` 前视 · `3` 右视 · `7` 顶视 · `0` 等轴测
- `V` 然后 `F`：缩放到所选对象

## 建议立刻改的两项

1. **编辑 → 首选项 → 零件设计 → 常规**  
   勾选“自动创建主体”（若有）。这样点“创建草图”时会自动生成 Body。
2. **编辑 → 首选项 → 草图 → 显示**  
   打开“约束时自动移除冗余约束”一类选项（名称随版本略有差异），减少新手被“过约束”弹窗打断。

## 插件管理器

**工具 → 插件管理器**。以后需要钣金（SheetMetal）、紧固件（Fasteners）、A2plus 等，从这里装，不要手动解压到系统目录。

第一次打开插件管理器需要联网。装完按提示重启 FreeCAD。

## 文件与备份

- 工程文件扩展名是 **`.FCStd`**（本质是 zip，里面是 XML + 形状）。
- **Ctrl+S** 常按。零件设计的特征历史一旦损坏，没有旧档会很难救。
- **文件 → 另存为** 在大改结构前做一份副本。
