# 05 其他常用工作台

零件设计做出单个实体之后，日常还会碰到：堆基本体、出工程图、把几个零件装在一起、用表格统管尺寸。

## 零件工作台（Part）

适合：概念验证、导入的 STEP 需要切一刀、写 Python 布尔（见第 7 章）。

不适合：还要反复改尺寸的正式零件——没有草图历史。

常用操作：

1. 切换到 **零件**。
2. **立方体 / 圆柱 / 球体** 创建基本体，在属性里改长宽高。
3. 选两个实体 → **差集 / 并集 / 交集**。
4. **变换** 里可平移旋转（这是一次性坐标，不是约束）。

零件设计的 Body 与零件工作台的实体尽量不要混在同一个历史里乱布尔。需要时：选中 Body → 创建形状绑定，或导出 STEP 再导入，当作“冻结的几何”。

## 工程图（TechDraw）

把 L 支架变成可打印的 PDF 图纸：

1. 切换到 **工程图**。
2. **插入新图纸**，选模板（A4 横向 `A4_Landscape_ISO7200TD` 一类）。
3. 在模型树选中实体（Body 或最终形状），点 **插入视图**。
4. 再插入 **投影视图** 得到前视 / 俯视 / 侧视，或用 **插入多视图**。
5. **直径标注 / 长度标注** 点视图里的边。
6. **文件 → 导出 PDF**，或打印。

TechDraw 标注的是视图上的 2D。改 3D 后点 **重计算**（Ctrl+R）更新视图。复杂零件若视图空白，检查是否选错了对象，或到属性里改 Scale。

## 装配（Assembly）

1.0 起内置装配工作台（Ondsel 求解器），1.1 增加了插入新零件、关节运动 **仿真**、物料清单属性输出。

最小流程：

1. 每个零件仍在自己的 Body / 文件里做完。
2. 新文档，切到 **装配** → **新建装配**。
3. 把零件拖进装配容器，或用 **插入组件**（建议用链接，原件留在装配外并隐藏，避免改错）。
4. 选作为机架的底座 → **接地（Grounded）**，否则整堆会漂。
5. 用 **接头**：面对齐、同心（轴孔）、平行等，把支架拧到板上。
6. **求解装配**。1.1 可用仿真给接头加运动做动画。

装配约束的是刚体之间的自由度，不是草图约束。孔对不齐时回到零件草图改孔距，不要在装配里硬挪。

## 电子表格驱动尺寸

1. 切到 **电子表格**，插入表格 `Spreadsheet`。
2. `A1` 写 `Length`，`B1` 写 `80`，把单元格别名设为 `Length`（选中单元格 → 属性 Alias）。
3. 回到草图尺寸，输入 `<<Spreadsheet>>.Length`。
4. 改表格里的 80，零件更新。

给研究用参数扫描时，表格比满屏幕的约束名称好维护。别名必须是合法标识符（英文开头）。

## 网格、FEM、CAM（知道即可）

| 工作台 | 用途 | 新手注意 |
|--------|------|----------|
| Mesh | 看 STL、简单修复 | 网格不是 CAD 实体，改不了参数 |
| FEM | 静力、频率等 | 需安装 CalculiX 等求解器 |
| CAM | 铣削刀路 | 1.1 刀具库是新系统，先在废料文件上试 |

钣金、螺纹紧固件、渲染等通过 **工具 → 插件管理器** 安装。
