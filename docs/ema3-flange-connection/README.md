# 派克 EMA3 接头与法兰连接设计

## 1. 设计结论

派克 EMA3 是 **SensoControl 外螺纹测压点接头**，测压端固定为 **M16×2 螺纹耦合**，油口端是外螺纹，**本身没有法兰面**。与法兰连接必须经过油口或转接件，不能把 EMA3 直接焊在法兰上，也不能用锥管螺纹当高压诊断口。

推荐优先级：

| 优先级 | 方案 | 适用 | 机加 | 额定压力（测压支路） |
| --- | --- | --- | --- | --- |
| 1 | **A 法兰颈径向 ISO 6149 油口** | 新制液压法兰、阀块、泵/马达壳体 | 要 | 以法兰为准，接头侧最高 630 bar |
| 2 | **C 测压隔板** | 已有 ISO 6162 / SAE J518 四螺栓法兰，不改本体 | 隔板自制或外购 | 以法兰 Code 61/62 为准 |
| 3 | **B G1/4 ED 油口** | 现场只有 BSPP 丝锥，或 1/2″ 小法兰空间不够 | 要 | EMA3/1/4ED 为 630 bar |
| 4 | **D 全部标准件转接** | 临时测压、无机床 | 否 | 取转接头与法兰较低值 |
| 5 | **E 管法兰焊接凸台** | GB/T、HG/T 管法兰、容器接管 | 焊后精加工 | 以管法兰 PN 为准 |

**默认选型（无特殊约束时）：**

- 新制件：法兰颈加工 **ISO 6149-1 M14×1.5** 诊断油口 + **EMA3/14X1.5ISO**
- 已有 SAE 法兰：加装 **t = 32 mm 测压隔板** + 同上接头
- 碳钢系统：订货号后缀 **CF**（无六价铬镀锌，NBR）
- 不锈钢 / 高温 / 磷酸酯：后缀 **71**（316Ti，FKM）

图样见 `drawings/`。

## 2. 设计依据

- Parker Catalogue 4100 / 3400-CN：EMA3、GMA3、VKA3、SMA3
- ISO 6149-1：公制直螺纹 O 形圈油口（M14×1.5 为诊断口优先规格）
- ISO 1179-1：BSPP（G）油口；ED 密封对应 Form E
- ISO 6162-1 / SAE J518 Code 61：四螺栓液压法兰（常用 210–350 bar 级）
- ISO 6162-2 / SAE J518 Code 62：高压四螺栓法兰（常用 420 bar 级）
- Parker 法兰样本：GFS、PFF-G、FHS、隔板（spacer plate）用法
- Parker Port End Assembly Guide：ISO 6149 / ISO 1179 装配扭矩

## 3. EMA3 接口特性

```
测压软管 SMA3  ← M16×2 螺纹耦合 ← EMA3 阀芯（锥面 + O 形圈）← 油口外螺纹 → 法兰侧
                                      ↑
                               金属自锁防尘帽
```

| 项目 | 规定 |
| --- | --- |
| 测压端 | M16×2，与 SMA3 测试软管、压力表、传感器同一体系 |
| 一次密封 | 锥面 + O 形圈（相对 EMA1 的钢球单向阀，泄漏更小） |
| 二次密封 | 软管接上后由 O 形圈完成 |
| 带压耦合 | 允许，上限 **400 bar** |
| 系列最高 PN | **630 bar**（取决于油口规格，见下表） |
| 防尘帽 | 自锁金属帽，振动场合不得用塑料帽替代 |
| 接口标准 | **ISO 15171-2**（M16×2 可带压耦合）。同接口：Minimess 1620 / STAUFF Test 20。**不是** EMA4 的 M16×1.5，也不是 EMA1 的插销式 |

### 3.1 M16×2 测压端用什么密封圈（不是油口端）

EMA3 **所有型号**的测压端都是 **M16×2**，与油口是 G1/4、M14 还是别的无关。这里的圈和油口上的 ED 圈、ISO 6149 圈 **不是同一件**。

派克 Catalogue 4100 原文：一次密封由 **锥面 + O 形圈** 完成；拧上金属帽、或接上 SMA3 软管后，帽/软管内的 O 形圈作 **二次密封**。阀芯打开前必须先密封（ISO 15171-2：螺纹至少啮合两牙后才顶开单向阀）。

```
金属帽 / SMA3 阴端  ← 二次 O 形圈
         M16×2 外螺纹（EMA3 本体）
         锥面 + O 形圈            ← 一次密封（阀芯侧）
         单向阀芯（内密封，见下）
```

| 位置 | 作用 | 材料（派克规定） | 公开备件 |
| --- | --- | --- | --- |
| **一次：阀芯锥面 O 形圈** | 测压端主密封，帽拧紧或软管接上后压在锥面上 | 钢件 CF 的 **内密封仍是 FKM**（4100：Standard-NBR-version 的 poppet 仍用 FKM）。71 不锈钢内外都是 FKM | **派克不单卖尺寸/料号**。泄漏时换整只 EMA3 |
| **二次：金属防尘帽 O 形圈** | 戴帽时二次密封 + 防振自锁 | 钢件外圈 **NBR**（−20~+100 °C）；71 为 **FKM**（−20~+200 °C） | 不单卖帽圈。戴帽漏油：换帽总成或整只接头 |
| **二次：SMA3 软管阴端 O 形圈** | 接表时二次密封（软管两端都是 M16×2 阴螺纹） | 随软管：钢件 NBR，不锈钢 FKM | 在软管阴端槽里，**不是**法兰油口那只圈。损坏换 SMA3 或派克软管端备件 |
| 阀芯内部 | 单向阀关闭时内部密封 | **一律 FKM**（4100：“Internal seals are always FKM”） | 不现场拆阀芯换圈 |

**不要用在 M16×2 上的东西：**

| 圈 / 垫 | 那是给谁的 | 用在 M16 会怎样 |
| --- | --- | --- |
| `ED14X1.5X`（11.6×16.5×1.5 DIN 3869） | 油口 **G1/4 ED**（`EMA3/1/4ED`） | 截面、沟槽都不对，压不密封 |
| `M-14 ISO O-RING` **11.3×2.2** | 油口 **ISO 6149 M14**（`EMA3/14X1.5ISO`） | 那是拧进法兰的那一头 |
| DIN 16258 / EN 837-1 铜垫 | 压力表 **G 螺纹**（`MAV1/4MA3` 表端） | 不是测压耦合 |
| 紫铜垫、生料带、厌氧胶 | — | M16 是锥面弹性密封，涂胶会卡死阀芯 |

市面有人按 11×1.5、12×1.5 卖“Minimess M16 密封圈”，**派克样本没有公布 ID×CS**，不能当正式备件写进图样。需要换圈时向派克订 EMA3 / SMA3，不要拿油口圈凑。

配套件：测试软管用 **SMA3-xxx**（两端 M16×2）；表接头 **MAV1/4MA3**（一侧 M16×2，一侧 G1/4 + EN 837-1）。**EMA4 / SMA4 是 M16×1.5**，螺纹牙距不同，不能拧到 EMA3 上。

### 3.2 与法兰相关的油口规格（摘录）

| 订货号（钢件加 CF） | 油口螺纹 | 密封形式 | 图型 | PN bar | 对边 S1 | 推荐用途 |
| --- | --- | --- | --- | --- | --- | --- |
| **EMA3/14X1.5ISO** | M14×1.5 | ISO 6149 O 形圈 | F | **630** | 19 | **诊断口首选** |
| **EMA3/1/4ED** | G1/4 | ED 弹性圈压端面 | B | **630** | 19 | 国内 BSPP 油口 |
| EMA3/12X1.5ED | M12×1.5 | ED | B | 630 | 17 | 小法兰、薄壁 |
| EMA3/3/8ED | G3/8 | ED | B | 630 | 22 | 较大凸台 |
| EMA3/10X1OR | M10×1 | ISO 6149 O 形圈 | A | 630 | 17 | 紧凑阀块 |
| EMA3/1/4 | G1/4 | 切削刃/垫圈类 | D | 400 | 19 | 不推荐新设计 |
| EMA3/14X1.5 | M14×1.5 | DIN 3852 端面 | D | 400 | 19 | 勿与 ISO 6149 油口混用 |

**禁止混配：** ISO 6149 油口只能配 `…ISO` 或 `…OR` 接头；ISO 1179 / DIN 3852 平面油口配 ED 或垫圈型。螺纹外径相近不等于密封面相同。

## 4. 先判定法兰类型

| 现场看到的法兰 | 标准 | 主密封 | 走哪条方案 |
| --- | --- | --- | --- |
| 四螺栓矩形、法兰头有 O 形圈槽 | ISO 6162 / SAE J518 | 平面静密封 | A 或 C 或 D |
| 泵/阀块上同样的四螺栓油口垫 | 同上 | 平面 | A（侧口）或 C |
| 圆形管法兰、PN 标记、垫片密封 | GB/T 9119、HG/T 20592 等 | 垫片 | E，或法兰短节上做方案 A |
| 阀块螺纹油口已是 G 或 M | ISO 1179 / 6149 | 接头自密封 | 直接拧 EMA3，不必再做法兰转接 |

Code 61 与 Code 62 **螺栓矩形不同，不能互换**。隔板和转接头必须与现有 Code 一致。

## 5. 方案 A — 法兰颈径向诊断油口（新制件首选）

### 5.1 结构

在法兰颈、阀块侧面或泵壳体上加工 **ISO 6149-1 M14×1.5** 油口，轴线垂直于主管，连通孔与主管相交。EMA3 拧入后，主法兰密封面不改动。

装配关系见 `drawings/02-scheme-a-hub-port.svg`，油口加工见 `drawings/03-iso6149-m14-port.svg`。

### 5.2 油口尺寸（M14×1.5）

| 符号 | 尺寸 mm | 说明 |
| --- | --- | --- |
| d1×P | M14×1.5-6H | ISO 261 |
| d2 宽型 | ≥ Ø25 | 带识别凸环的 spotface，推荐 |
| d2 窄型 | ≥ Ø21 | 无凸环 |
| d3 | Ø7.5 | 连通孔，可按流量略改 |
| d4 | Ø19.5（0/+0.1） | 密封孔 |
| d5 | Ø15.8（0/+0.4） | 锥底直径 |
| L1 | ≥ 2.4 | 沉孔深 |
| L4 | ≥ 11.5 | 全螺纹最小长度 |
| Z | 15° ±1° | 密封锥，必须用成形刀 |

表面：密封锥与端面 Ra ≤ 1.6 μm。零件上标注 `ISO 6149` 或 `METRIC`。

### 5.3 法兰颈强度与布置

- 凸台外径建议 ≥ Ø32，凸台高出外圆 ≥ 2 mm，保证 Ø25 端面完整。
- 连通孔与主管相交处去毛刺，禁止残留切屑进入系统。
- 油口轴线避开四条法兰螺栓及对开夹；按 S=19 扳手预留回转空间。
- 剩余壁厚由工作压力和材料核算。ISO 6149 本身不给壁厚数值，钢制 630 bar 诊断口经验值为：spotface 外到自由表面 ≥ 6 mm，且螺纹根部不切入主密封面或螺栓孔。
- 法兰颈太薄时不要强行攻丝，改方案 C。

### 5.4 安装扭矩

润滑装配，钢接头 + 钢油口：

| 接头 | 油口 | 扭矩 |
| --- | --- | --- |
| EMA3/14X1.5ISO | ISO 6149-3 L 系列 M14×1.5 | **35 N·m**（+10%/−0） |
| 不锈钢 71 | 同上 | 取上限，约 38 N·m |
| 铝 / 铜阀体 | 同上 | 降低约 35% |

步骤：检查 O 形圈完好 → 系统介质或相容油脂薄涂 → 手拧到位 → 扭矩扳手拧紧 → 防尘帽拧紧。

## 6. 方案 B — G1/4 ED 油口

当现场工艺是 BSPP、或 1/2″ 法兰侧面放不下 Ø25 spotface 时采用。

| 项目 | 规定 |
| --- | --- |
| 油口 | ISO 1179-1 **Type W（宽型端面）G1/4** |
| 接头 | **EMA3/1/4ED** |
| 密封 | ED 弹性圈压在油口端面，螺纹不密封 |
| 端面 | Type W 参考约 Ø20.7，沉孔/倒角按 ISO 1179 |
| 全螺纹 | ≥ 12.5 mm |
| 连通孔 | Ø7.5 |
| 扭矩 | **40 N·m**（G1/4 Form E，钢件润滑；Parker 表 R2 对 G1/4 ED 为 35–45 N·m 档，取 40） |
| PN | 630 bar（接头）；支路仍受法兰限制 |

窄型 Type N 端面偏小，ED 圈容易压偏，新设计一律 Type W。

## 7. 方案 C — 测压隔板（不改原法兰）

派克法兰样本中的 spacer plate：夹在两法兰头之间，侧面提供测压口。原法兰 O 形圈仍在槽内工作，隔板两面为平面。

见 `drawings/04-scheme-c-spacer.svg`、`drawings/05-spacer-plate.svg`。

### 7.1 两种密封配置

| 配置 | 两侧法兰 | 隔板密封面 |
| --- | --- | --- |
| **C1（常用）** | 至少一侧法兰头带 ISO 6162 O 形圈槽 | 两面平面 |
| C2 | 两侧都是平面油口垫 | 隔板两面按 ISO 6162 开槽并装 O 形圈 |

### 7.2 推荐隔板参数

- 材料：42CrMo4 调质 28–32 HRC，或 316L
- 厚度 **t = 32 mm**（M14 ISO 6149 侧面 spotface Ø25 需要足够板厚）
- 1/2″ 若仍干涉：改 G1/4 ED，t = 26 mm，或保持 t = 32 且油口开在螺栓矩形**长边**中点
- 螺栓：原 12.9 级，**加长量 = t + 原垫圈方案不变时的补偿**；对角分步拧到下表
- 贴合面：平面度 0.03 mm / 100 mm，Ra ≤ 1.6 μm

ISO 6162-1 Code 61 隔板几何（mm）：

| 通径 | 法兰 | 内孔 d | 螺栓距 a | 螺栓距 b | 螺栓 | 外形约 L×W | 测压口 |
| --- | --- | --- | --- | --- | --- | --- | --- |
| DN13 | 1/2″ | 13.5 | 38.1 | 17.5 | M8 | 56×48 | G1/4 ED 优先 |
| DN19 | 3/4″ | 19.5 | 47.6 | 22.2 | M10 | 66×54 | M14 ISO 或 G1/4 ED |
| DN25 | 1″ | 25.5 | 52.4 | 26.2 | M10 | 72×62 | **M14 ISO** |
| DN32 | 1-1/4″ | 32.5 | 58.7 | 30.2 | M10 | 82×74 | M14 ISO |
| DN38 | 1-1/2″ | 38.5 | 69.9 | 35.7 | M12 | 96×84 | M14 ISO |
| DN51 | 2″ | 51.5 | 77.8 | 42.9 | M12 | 104×98 | M14 ISO |

ISO 6162-2 Code 62 必须改用对应螺栓距（例如 1″ 为 57.2×27.8，M12），不得用上表。

Code 61 法兰螺栓扭矩（Parker，公制）：

| 法兰 | 螺栓 | 扭矩 N·m |
| --- | --- | --- |
| 1/2″ | M8 | 25 |
| 3/4″、1″ | M10 | 49 |
| 1-1/4″、1-1/2″ | M10 / M12 | 85 |
| 2″ | M12 | 92 |

装配：清洁密封面 → O 形圈涂液压油入槽 → 放入隔板 → 对开夹与螺栓手拧 → 对角分步达扭矩 → 再装 EMA3。

## 8. 方案 D — 全部用派克标准件

不机加法兰本体时，按现有法兰选转接，再接到 EMA3 油口。

| 路径 | 零件链 | 说明 |
| --- | --- | --- |
| D1 | 法兰垫 + **PFF-G**（法兰→G 内螺纹）→ 变径 **RI-ED** → EMA3/1/4ED | 块式转接，刚性好 |
| D2 | **GFS**（法兰→EO 24°）→ 硬管 → **GMA3** | 测压点在管路上，软管体系仍是 M16×2 |
| D3 | 法兰软管接头 + 诊断三通（ORFS/37°）→ EMA3 | 适合胶管总成 |
| D4 | **WFS** 90° 法兰弯头带侧口或后续三通 | 空间只允许侧向引出时 |

压力取整条链最小值。Code 61 的 PFF/GFS 常见 207–345 bar，低于 EMA3 的 630 bar，**按法兰额定使用**。

## 9. 方案 E — 管法兰（GB/HG/DIN）

圆形管法兰没有 ISO 6162 油口垫。做法：

1. **预制测压短节**：一端配原管法兰，短节圆柱上按方案 A 加工 ISO 6149 油口，对焊或螺栓连接接入管线。
2. **焊接螺纹凸台**：凸台先粗加工，焊在法兰颈或接管上，焊后去应力，再精锪 ISO 6149 油口。禁止焊后在焊缝区直接攻丝。
3. 凸台材质与主管匹配（碳钢对碳钢，不锈钢对不锈钢），焊接工艺按 GB 50236 / 相应压力管道规程。

管法兰 PN16/25/40 远低于 630 bar，测压支路按管法兰 PN。

## 10. 选型流程

```
有没有现成螺纹油口？
 ├─ 有，且是 ISO 6149 M14 / M10 → 直接 EMA3/…ISO 或 …OR
 ├─ 有，且是 G1/4 平面 → EMA3/1/4ED
 └─ 没有
      ├─ 新制液压法兰/阀块 → 方案 A
      ├─ 已有 SAE 四螺栓连接 → 方案 C
      ├─ 不能机加 → 方案 D
      └─ 管法兰/容器 → 方案 E
```

系统压力：

- ≤ 210 bar：Code 61 或管法兰 PN25 通常足够
- 210–350 bar：Code 61 需核对具体通径额定；优先 Code 62 或 PN40 以上
- 350–420 bar：Code 62 + EMA3 630 bar 规格
- 带压接表：工作压力 ≤ 400 bar

## 11. 材料、密封件、环境

| 工况 | 接头 | 隔板 / 法兰 | 密封 |
| --- | --- | --- | --- |
| 矿物油，−20~+80 °C | EMA3/…CF | 42CrMo4 镀锌无 Cr(VI) | NBR |
| 高温或磷酸酯 | EMA3/…71 | 316L / 316Ti | FKM |
| 户外振动 | 金属自锁帽 | 12.9 螺栓 + 弹垫或防松 | 按上 |

M16×2 测压端的锥面圈 / 帽圈派克不单卖，泄漏换整只 EMA3 或 SMA3。油口端的 ED 圈、ISO 6149 圈才有备件号（`ED14X1.5X`、`M-14 ISO O-RING` 11.3×2.2），**不要拿到 M16 上用**。不得用生料带、密封胶代替。

## 12. 配套测压附件

| 用途 | 型号 |
| --- | --- |
| 测试软管 | SMA3-xxx（xxx 为长度 mm），两端 M16×2 |
| 管路中间测压（卡套） | GMA3/…L 或 …S |
| 压力表测点 | VKA3/… |
| 不用时 | EMA3 原装防尘帽必须装回 |

GMA3 用于硬管 24° 锥体系，**不能**代替法兰主连接，只作为方案 D2 的管路测点。

## 13. 检验与验收

1. 油口用 ISO 6149 塞规 / 成形刀清单核对，15° 锥面无磕碰。
2. 隔板螺栓孔距 ±0.25 mm，贴合面着色检查连续。
3. 装配后 **1.5 倍系统工作压力** 保压（不超过法兰和接头额定），测压口先戴帽。
4. 功能试验：卸帽、接 SMA3、带压（≤400 bar）耦合应无可见外漏；拆软管后阀芯关闭，再戴帽。
5. 标识：法兰或隔板旁标注油口标准（ISO 6149 或 G1/4 ED）和接头订货号，避免日后错配。
