# 03 草图与约束

草图（Sketch）是参数化建模的地基。零件设计里的填充、开槽、旋转，吃的都是 **闭合、不自交、尽量完全约束** 的轮廓。

## 进入草图

在 **零件设计** 中：

1. 点 **创建草图**。若还没有主体，FreeCAD 会自动建一个 Body。
2. 选择附着平面，例如 **XY_Plane**。
3. 确定后，界面切到草图工具，3D 视图变成正对草图的 2D 纸。

原点十字是草图坐标系。后面所有尺寸都相对这些几何（或相对你锁住的点）。

## 先画形，再约束

推荐顺序：

1. 用矩形、圆、多段线 **大概画出形状**（尺寸先随便）。
2. 加 **几何约束**：水平、竖直、重合、相切、相等、对称。
3. 最后加 **尺寸约束**：长度、半径、角度、点到点距离。
4. 看求解器：欠约束 → 继续加；完全约束 → 关闭草图。

不要一上来就把每条线都标成尺寸。几何约束（“这两条线平行且等长”）比一堆重复尺寸更稳。

## 几何工具（够用的子集）

| 工具 | 用途 |
|------|------|
| 折线 / 直线 | 外轮廓 |
| 矩形 | 底板、槽 |
| 圆 / 圆弧 | 孔、圆角轮廓（实体圆角更好用圆角特征） |
| 槽形 | 长圆孔 |
| 圆角（草图内） | 轮廓倒圆；数量多时优先用零件设计圆角 |
| 修剪 | 剪掉多余线段，保证闭合 |
| 外部几何 / 投影（1.1） | 把已有边投影到当前草图，用来对齐 |

画完轮廓后检查：**所有端点要粘在一起**。放大看，差 0.01 mm 的缝会让填充失败。用 **重合约束** 把端点吸到一起，或开自动约束（画线时靠近端点出现红点再松手）。

## 约束颜色在说什么

| 状态 | 常见外观 | 含义 |
|------|----------|------|
| 欠约束 | 白 / 黄几何 | 还可以拖动某些点。允许暂时存在，但关闭前应尽量约束完 |
| **完全约束** | **绿色** | 形状被尺寸和几何关系钉死，改尺寸才会变形。这是目标 |
| 过约束 | 橙 / 红，弹出冲突 | 约束互相打架。删掉红色冲突约束，不要硬点确定 |
| 构造几何 | 蓝虚线 | 只当辅助线，不参与填充轮廓 |

任务面板顶部会显示类似 `约束: 12/12` 或 “完全约束”。1.1 还会在状态栏给当前工具提示。

## 几何约束速记

| 约束 | 典型用法 |
|------|----------|
| 水平 / 竖直 | 矩形边对齐全 |
| 重合 | 端点相连、圆心落在原点 |
| 点在线上 | 中点、对称辅助 |
| 相等 | 两个孔同直径，只标一次直径 |
| 对称 | 两孔关于中线对称 |
| 相切 | 圆弧接直线 |
| 锁定 | 把点钉在当前位置（少用，优先用到原点的尺寸） |

**命名尺寸**：双击尺寸约束，除了改数值，可把名称改成 `Length`、`HoleDia`。后面电子表格或表达式可以用 `Sketch.Constraints.HoleDia` 引用。

## 表达式（改一处，处处更新）

尺寸框里可以写公式，例如：

- `80 - 2*8`
- `HoleDia / 2`
- `<<Spreadsheet>>.Length`

单位默认跟文档走。写 `10 mm` 或纯数字都可以，混用英寸时才需要显式单位。

## 闭合轮廓规则

给 **填充 / 开槽** 用的草图应当：

- 外轮廓闭合
- 内部的圆表示要挖掉的孔（一个草图里可以同时有外框和内孔）
- 不要有 T 形交叉、重复线、零长度线
- 不要把构造几何画成实线轮廓的一部分却不相连

若填充报错 `wire is not closed` 或 `shape is invalid`，回到草图：

1. **草图 → 校验草图**（或任务面板里的校验）。
2. 用修剪去掉伸出的线头。
3. 把重合约束补上。

## 编辑已有草图

模型树中双击 `Sketch`，或选中后点“编辑草图”。改完关闭，后续填充会重算。

若草图附着在已经被开槽删掉的面上，特征会变黄/红（拓扑命名问题）。尽量：

- 把关键草图附着在 **基准面** 而不是临时面上；或
- 少改早期特征的“面的数量”，先定主形状再打孔倒角。

## 练习（2 分钟）

新建草图，XY 平面：

1. 画矩形，左下角与原点重合。
2. 宽 `80 mm`，高 `50 mm`。
3. 画两个圆，半径用相等约束，再标一个直径 `8 mm`。
4. 两圆心关于矩形竖直中线对称，距短边 `16 mm`，沿宽度方向居中。

完成后应完全约束、呈绿色。这套孔位会在下一章用到。
